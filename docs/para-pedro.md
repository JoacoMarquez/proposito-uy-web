# Propósito UY — Cosas que necesito de vos, Pedro

¡Hola Pedro! La web ya está bastante avanzada y te paso el link para que la vayas
viendo. Para poder dejarla 100% lista y publicarla en `propositouy.com.uy`, hay
algunas cosas que dependen de vos. Te las agrupé por tema. No hace falta que las
tengas todas juntas: lo que me vayas pasando, lo voy cargando.

> 👀 **Para ver la web:** te comparto un link de previsualización. Lo que veas ahí
> ya es la web real funcionando; algunas fotos y datos todavía son de muestra
> (te aviso cuáles abajo) y se completan con lo que me pases.

---

## 1. Datos del negocio

- **Datos bancarios para transferencias.** Banco, titular de la cuenta, número de
  cuenta (y sucursal si corresponde), y alias si tenés. Hoy, cuando un cliente
  elige pagar por transferencia, la web le dice "datos bancarios: pendientes de
  cargar". Con esto queda completo.
- **Email para tu acceso al panel.** ¿Con qué correo querés entrar a administrar
  la web (cargar productos, ver pedidos, etc.)? Con ese email te creo el usuario.
- **Datos para las páginas legales.** Para las páginas de *Privacidad*, *Términos*
  y *Cookies* necesito: razón social / nombre con el que facturás, **RUT**, y
  quién figura como responsable de los datos. (Los textos ya están redactados;
  esto completa los datos formales. Idealmente que un contador o abogado les dé
  una mirada antes de publicar.)

## 2. Contenido (textos y fotos)

- **Fotos de productos y recetas.** ¡Buena noticia! Ya podés **subir y cambiar las
  fotos vos mismo** desde el panel de administración, sin depender de mí. Igual,
  si querés, pasame el material que tengas (sobre todo fotos de **recetas** y de
  la sección **Nosotros**) y las cargo yo.
- **Textos finales.** ¿Los textos institucionales (Nosotros), descripciones de
  productos, etc., están como querés, o tenés una versión final para reemplazar?
- **Tablas nutricionales.** En la página de *Preguntas* va un botón "Ver tablas
  nutricionales". ¿A dónde querés que lleve? Puede ser un link a una planilla de
  Google / Drive, o un PDF que me pases para subir al sitio. (Mientras no esté, el
  botón no aparece.)
- **Imagen para compartir.** Cuando alguien comparte la web por WhatsApp o redes,
  se muestra una imagen de vista previa. Lo ideal es una imagen de marca dedicada
  (tamaño 1200×630 px). Hoy se usa una foto de producto por defecto.

## 3. Confirmación

- **Recargo de Barras Mix (Cajú).** La calculadora de la caja personalizada ya
  está hecha: suma **$16 extra por cada barra de Cajú**. Solo necesito que me
  **confirmes que ese monto es correcto** (si cambia, lo ajusto en un segundo).

## 4. Accesos técnicos (cuando lleguemos a publicar)

- **Dominio `propositouy.com.uy`.** Para conectar el dominio a la web voy a
  necesitar acceso al panel donde se administra el dominio (Hostinger), o que vos
  agregues unos registros que te pase.
- **Correo `@propositouy.com.uy`.** Si querés usar casillas con el dominio, lo
  coordinamos con el mismo acceso.
- **Envío de mails de confirmación.** La web manda un mail automático cuando entra
  un pedido. Para que salgan desde una dirección tuya hay que verificar el dominio
  (te paso los pasos / registros cuando estemos en esta etapa).
